그린힐링 스튜디오

누적 조회수 불러오는 중

프로젝트 소개

여러 터프팅 공방이 함께 입점하는 통합 쇼핑몰 플랫폼입니다. 완제품·재료 판매부터 원데이 클래스 예약, 주문제작 신청까지 공방과 소비자를 한 곳에서 연결하여, 기존 단일 공방 구조의 한계를 넘어 터프팅 생태계 전체를 하나의 서비스로 묶는 것을 목표로 합니다.

주요 기능

  • 터프팅 완제품·재료 판매 (장바구니, 테스트 결제)
  • 공방별 원데이 클래스 예약
  • 주문제작(커스텀) 신청 및 진행 현황 확인
  • 공방 관리자 페이지 — 상품·클래스·주문제작 관리
  • 플랫폼 관리자 페이지 — 공방 입점 승인 및 전체 관리

사용 기술

Backend: Java, Spring Boot / Database: MySQL / Deploy: AWS Elastic Beanstalk, AWS RDS / Tools: IntelliJ IDEA, Git

팀 소개

컴퓨터공학과 2324074 한세빈 — 단독 개발, 기획·백엔드·배포 전 과정 담당

API 연결 확인

페이지를 열거나 새로고침하면 조회수가 증가합니다.
